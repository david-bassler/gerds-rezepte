# Gerds Rezepte

Statische Website des privaten Rezeptarchivs „Gerds Rezepte“.

## GitHub Pages

Die Seite benötigt keinen Build-Prozess. GitHub Pages kann direkt den Inhalt des `main`-Branches aus dem Repository-Root veröffentlichen.

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)`.
